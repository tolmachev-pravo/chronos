**События исполнителя**
Поиск находит задачи, в которых вы указаны исполнителем и которые в выбранном периоде были в статусе «В работе».
Интервалы берутся из истории изменений статуса: каждый переход в «В работе» и обратно даёт предполагаемый ворклог.
Это основной источник событий — с ним раздел Worklogs показывает вашу работу по задачам.
