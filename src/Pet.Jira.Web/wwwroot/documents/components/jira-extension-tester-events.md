**События тестировщика**
Поиск находит задачи, где в поле «Tester» указаны вы и которые в выбранном периоде были в статусе «В тестировании».
Интервалы берутся из истории изменений статуса: каждый переход в «В тестировании» и обратно даёт предполагаемый ворклог.
Пока настройка выключена, такие задачи не запрашиваются из Jira — поиск в Worklogs работает быстрее.
