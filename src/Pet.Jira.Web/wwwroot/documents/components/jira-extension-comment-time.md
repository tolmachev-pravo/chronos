**Время комментария**
Длительность предполагаемого ворклога, который создаётся из одного вашего комментария.
Применяется к каждому найденному комментарию; при нулевом значении события по комментариям будут с нулевой длительностью.
Настройка действует только при включённых событиях по комментариям.
**по умолчанию**: 00:00
