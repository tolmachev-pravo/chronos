Раздел **«Релизы»** собирает историю обновлений приложения в одном месте. Данные берутся
напрямую со страницы релизов проекта в GitHub, поэтому список всегда актуален и не требует
ручного ведения: как только вышел новый релиз на GitHub, он появляется и здесь.

![Релизы из GitHub на странице приложения](/documents/features/releases-section/images/releases-flow.svg)

## Что это даёт

- Быстрый обзор, что нового в приложении, без перехода на GitHub.
- Каждый релиз — карточка с названием, версией (тегом), датой публикации и описанием
  (Markdown из release notes).
- Пометка **Pre-release** для предварительных версий.
- Ссылка «Открыть на GitHub» на каждой карточке для перехода к полному релизу.

## Как пользоваться

1. Откройте пункт **Releases** в боковом меню.
2. Пролистайте список — релизы отсортированы от новых к старым.
3. Нажмите ссылку на карточке, чтобы открыть релиз на GitHub.

> 💡 Список кэшируется на несколько минут, поэтому повторное открытие раздела происходит
> мгновенно и не нагружает GitHub лишними запросами.

> ⚠️ Если приложение не может достучаться до GitHub (например, из-за сетевых ограничений),
> раздел не падает с ошибкой, а показывает сообщение с кнопкой **«Открыть релизы на GitHub»** —
> релизы всегда можно посмотреть напрямую в браузере. Пока GitHub недоступен, показывается
> последняя успешно загруженная версия списка, если она есть.
